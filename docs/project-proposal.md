# Project Proposal

## Project Title
Autonomous AI-Based Drone for Indoor Building Mapping

## Student
Omran Shibli

## Objective
The goal of this project is to develop an AI-based drone system capable of scanning indoor environments, collecting distance measurements, detecting obstacles, and generating a basic 2D digital map.

## Problem
Indoor building mapping is often performed manually or using expensive scanning systems. This process can be time-consuming, costly, and requires trained operators.

## Proposed Solution
The proposed system uses a drone equipped with a Raspberry Pi, camera, ToF/LiDAR sensors, and a Pixhawk flight controller. The drone collects visual and distance data while moving indoors and uses computer vision and mapping algorithms to generate a 2D map.

## Expected Output
- Basic 2D indoor map
- Approximate room length and width
- Obstacle detection
- Real-time data processing
