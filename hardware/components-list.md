# Hardware Components

## Main Components

- Raspberry Pi 5
- Raspberry Pi Camera Module
- Pixhawk Flight Controller
- ToF / LiDAR Distance Sensor
- Drone Frame
- 4 Brushless Motors (BLDC)
- 4 ESCs (Electronic Speed Controllers)
- LiPo Battery
- Power Distribution Board

## Communication

- UART
- I2C
- SPI

## Purpose

The hardware system enables autonomous indoor navigation, obstacle detection, room measurement, and real-time map generation
