# Autonomous Indoor Mapping Drone

## Overview
This project aims to develop an AI-based autonomous drone capable of indoor building mapping, obstacle detection, and room measurement.

## Features
- Indoor navigation
- Obstacle detection
- Room dimension estimation
- 2D map generation
- Raspberry Pi based processing
- Computer Vision using OpenCV

## Hardware
- Raspberry Pi 5
- Camera Module
- ToF / LiDAR Sensors
- Pixhawk Flight Controller
- Drone Platform
- LiPo Battery

## Software
- Python
- OpenCV
- Computer Vision
- AI Algorithms

## Expected Output
The drone will scan indoor environments, collect distance measurements, detect obstacles, and generate a basic 2D map of the scanned area.
